## 0 1 — P R O J E C T

**SYLAGE Archive** is a living collection of moods, silhouettes, and visual compositions.

Moodboards form the starting point: images, colors, atmospheres, and tags come together to create a visual direction, from which new looks and silhouettes can emerge.

## 0 2 — F E A T U R E S

- Predefined moodboard layouts
- Images, colors, atmospheres, and tags
- Published moodboards and likes
- Looks and silhouette contributions
- Following and followers
- Moodboard image export

## 0 3 — T E C H N O L O G Y

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
- Vercel

## 0 4 — S E T U P

```bash
git clone https://github.com/Loreenbh/sylage-archive.git
cd sylage-archive
npm install
npm run dev
```

A Supabase project and the required environment variables are needed for local use.
